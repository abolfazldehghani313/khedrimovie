# VOD Platform V1 — Admin & Mobile Edition

نسخه آماده جایگزینی پروژه Flask VOD.

## تغییرات این نسخه
- پنل مدیریت با داشبورد، فیلم‌ها، سریال‌ها، فصل/قسمت، ژانرها، کاربران، اشتراک‌ها، پرداخت‌ها، تبلیغات، گزارش تماشا، نظرات، کد تخفیف و تنظیمات.
- سایدبار مدیریتی حرفه‌ای با آیکون‌های SVG.
- منوی ثابت پایین موبایل: خانه، فیلم، سریال، جستجو، پروفایل با ظاهر شیشه‌ای.
- ثبت‌نام با شماره موبایل.
- شماره `09055018315` به‌صورت خودکار مدیر می‌شود.
- ورود با ایمیل یا شماره موبایل.
- مهاجرت خودکار دیتابیس قدیمی برای اضافه‌کردن ستون `phone`.

## اجرا
```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

آدرس: `http://127.0.0.1:5000`

در اولین اجرا دیتابیس ساخته و داده‌های نمونه Seed می‌شوند.
